## 定档复核与建议（工程判断，判据字面无全达标档）

字面判据（翻转 0 漏检 ∧ 一致率 ≥98%）下无档双达标，但两指标当前**不可兼得的原因不同质**：

1. **一致率是当前唯一可用可信指标**：4B 99.18% 唯一达标（2B/8B 差 21.4/8.4pp）。
2. **「翻转 0 漏检」在现有真值上不可充分评估**：翻转真值只有 3 行人标（2026-09-05 期，
   数据集最早期），且 glm 时代对翻转的检出本就是 0（435 行 vision_verdict 无一「翻转」，
   rotation-analysis 实证 glm 对本风格旋转不可靠）——「漏检」分母（3）与「基准检出能力」
   （0）都说明该判据在今天更多是占位。8B 达标（3/3 命中）的代价是 **37 个假翻转**：
   VLM 判翻转 → 自动重生成 ≤1 轮（40-75s GPU/段），37 次/期 无谓重烧，运营上直接出局；
   2B 更是 54 个。
3. **机器判读定位 = 辅助信号**（rotation-analysis 实证 + ADR 0007 沿用）：旋转主防线是
   s07 横移运镜门 + 确认门④九宫格人审。4B 的 3 个「漏检」落到人审主防线，保护等级与
   glm 时代持平；4B 的 3 个「假翻转」（09-06:shot13、09-09:shot16 等）反而可能是 glm 漏报
   的真翻转——重生成 ≤1 轮的代价（3 次/期）可接受。
4. **翻转灵敏度提升走 CLIP 数据飞轮**（spec 既定分工）：本地化后每日机判结论持续积累 +
   人审纠偏回填 user_flagged，T7 线性探针承担翻转检出；届时 reconcile 双路合成自然补齐。

### 结论
