# ADR 0002：人物镜头政策——取消人物/近景禁令，改为内容驱动的逐段判断

- 状态：已接受（2026-09-05，用户拍板）
- 上下文：读报标准（2026-08-29 定稿）曾硬性禁人物/近景；实际成因是「不用真人形象」红线被放大成
  「无人物、无近景」。0904 跑单台账显示导演设计 21 全景 + 2 大全景、横移类运镜 23/23（100%），
  零中景/特写/人物主体——用户反馈画面单调。且「长卷横移」模板正是 H3 渲染 90° 旋转的高危运镜
  （5/5 实锤旋转镜头，见 ADR 0001 与 references/rotation-analysis-20260905.md）。

## 决策

1. **取消**「不要人物、不要近景」的一刀切禁令；改为**内容驱动的逐段判断**（导演层职责）：
   台词的信息/情绪落在人身上 → 人物中近景/特写；落在宏观 → 空镜或人物比例锚点；情绪爆点 → 特写。
   不设机械配额。
2. **保留三条红线**（与单调无关，不随本决策放开）：
   - 仅虚构仙侠角色，禁真实/可辨识人物（新闻内容安全；发布端已有 AI 生成声明）；
   - 画面内无人声，人物嘴唇闭合（口播是旁白契约；近景变多后此条更关键）；
   - POV 段仍为第一人称手部视角（构图概念，非人物禁令）。
3. **反模板硬约束**：相邻段不得同景别+同运镜；横移类运镜全片 ≤ 1/3；s5 台账记录景别分布与
   横移占比（`report.json` → `s04.shot_types` / `s04.lateral_design_ratio`；键名 s5 为阶段号
   重整（2026-09-07）前旧称，实际落盘 s04 块），超限在确认门摘要提醒。

## 后果

- 画面层次：人物镜头与宏大空镜交替，消除全片空镜单调；横移占比下降同时降低旋转风险。
- 判断质量依赖云端导演模型；台账逐期验证（shot_types 分布、lateral_design_ratio），
  若仍模板化，下一步升级为七项自检的新增检查项。
- 落点：SKILL.md 硬约束 5、director_llm.py SYSTEM_SHOT 规则 6/7、
  styles/chinese-celestial-palace.md（人物比例/负向约束/H3 关键词三处，~/ 与 repo 两份同步）。
