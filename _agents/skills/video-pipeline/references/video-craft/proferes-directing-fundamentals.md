# 《Film Directing Fundamentals》决策规则表 — Nicholas T. Proferes · 2026-08-26

- **作者**：Nicholas T. Proferes（尼古拉斯·普罗费雷斯）
- **来源**：2001《Film Directing Fundamentals: See Your Film Before Shooting》
- **技术域**：① 电影语法 ② 戏剧元素 ③ 戏剧块与支点 ④ 调度 ⑤ 摄影机 ⑥ 与演员合作
- **对齐字段**：shot_type（景别/机位/运动类型）、节奏意图（戏剧块/支点/揭示）、continuity_handoff（180°/30°/银幕方向）

## 1. 电影语法（Film Grammar）

| 触发信号 | 选什么/做什么 | 为什么 | 反例 |
|---|---|---|---|
| 两个角色面对面/对视 | 在两人间建立轴线（180°线），机位全留在同一半圆 | 保持屏幕方向一致，观众不迷路 | 跳到轴线另一侧拍→两人看同方向=空间崩坏 |
| 必须越线（换空间/反转位置） | 四种方式：dolly 跨线 / 切双人镜 / 切无关 切出（cutaway） / 角色自己跨线 | 建立新轴线，观众跟随不迷路 | 无动机直接跳对侧 |
| 越线产生戏剧效果 | 在"能量动作"（心理或物理转折）上越线 | 越线本身制造空间反转=戏剧标点 | 平淡对话中越线=混乱 |
| 同一角色/物体连续两镜 | 机位角度至少差 30° | 防 跳切（jump cut）（镜头像在空间里跳跃） | 差 <30°→观众察觉剪辑=出戏 |
| 30° 规则的例外 | 主体在运动 / 前景有物体 / 景别变化足够大 | 三种缓解因素让 <30° 也可接受 | 无缓解因素硬切<30° |
| 角色移动方向 | 左→右出画 → 下一镜左入画继续右移 | 维持屏幕方向=观众理解"同一方向" | 出右入右=像 U-turn |
| 需要制造张力 | 角色右→左移动（比左→右更紧张）；右→左+向上=最大张力 | 阅读习惯：左→右=舒适，右→左=紧张 | 所有运动都左→右=无张力变化 |
| 压缩无聊时间 | 省略/跳切加速 | 观众不需要看到全程 | 平铺直叙走完每一步=乏味 |
| 扩展有趣时刻 | 用多角度/慢动作/ elaboration 延长 | 关键时刻值得放大 | 关键时刻一镜带过=浪费 |

## 2. 戏剧元素（Dramatic Elements）

| 触发信号 | 选什么/做什么 | 为什么 | 反例 |
|---|---|---|---|
| 拿到剧本、不知从何分析 | 先问"这是谁的戏"（Whose film is it）→ 再找 脊梁（Spine）（脊梁=主角整体目标） | 脊梁决定一切戏剧元素的归属 | 从摄影/美术开始想=本末倒置 |
| 分析角色 | 逐层拆：角色/处境/动态关系/欲望/期待/动作/活动/表演节拍 | 每层是独立的戏剧杠杆 | 混在一起说"这个角色很复杂" |
| 动态关系 | 用角色"此刻怎么看对方"定义（如"骑士"→"枷锁"），可随故事变 | 动态关系是"现在时"的，驱动情感变化 | 用固定标签（"他们是夫妻"） |
| 欲望（Wants） | 欲望 < 脊梁（小目标），场景欲望更小；欲望必须有障碍 | 障碍=冲突=戏剧旅程 | 欲望无障碍→"你爱我吗？""爱"→全剧终 |
| 动作（Actions） | 角色一次只做一个动作；用动作动词描述（to reprimand/to seduce） | 动作=角色为达欲望做的事；情绪不可演 | 让演员演"情绪"——情绪来自动作+欲望+关系 |
| 对话=动作 | "Hello" 可以是问候/训斥/求和——取决于语境与欲望 | 对话的功能由处境与欲望决定 | 只看字面意思理解台词 |
| 活动≠动作 | 等牙医时看杂志=等待（动作），看杂志=活动 | 活动是伴随动作的，不是动作本身 | 把活动当动作拍=拍错重点 |
| 表演节拍（Acting Beat） | 角色动作改变=新节拍开始；每个节拍用一个动作动词 | 节拍是导演和演员的共同语言 | 用"感觉"而非动词描述节拍 |

## 3. 戏剧块与支点戏剧块（Dramatic Blocks）/叙事节拍（Narrative Beats） / Fulcrum）

| 触发信号 | 选什么/做什么 | 为什么 | 反例 |
|---|---|---|---|
| 一场戏不知怎么组织 | 拆成**戏剧块**（dramatic blocks）= 段落，每块一个主要动作（to reason/to seduce/to threaten/to beg） | 分离主要动作给它们更多力量和清晰度 | 一场戏混在一起=观众不知道在发生什么 |
| 戏剧块之间 | 每块给**显著不同的空间呈现**（地理段落） | 空间变化=动作意图+绝望程度的外化 | 所有块在同一位置拍=缺乏叙事推力 |
| 导演何时切镜/移机/移人 | 在**叙事节拍**（narrative beat）处——动作升级或方向改变的关键时刻 | 叙事节拍是导演对故事的标点；一切调度和剪辑为它服务 | 随机切镜/移人=没有叙事逻辑 |
| 场景中"可能往任何方向走"的时刻 | 标记为**支点**（Fulcrum）= 场景的转折点 | 支点=角色可能赢也可能输的关键时刻，是全场景最重要节拍 | 把支点当普通节拍处理=错失高潮 |
| 支点 vs 转折点 | 支点=一场戏内的转折；转折点=全片结构（幕末） | 一部10场戏的片有10个支点但只有2个转折点 | 混用两个概念 |

## 4. 调度（Staging）

| 触发信号 | 选什么/做什么 | 为什么 | 反例 |
|---|---|---|---|
| 调度的根本原则 | 所有调度必须服务**故事的外显动作**或**让内在心理变可见** | 无动机的移动是"戏剧张力最大的敌人" | 为了"让画面活起来"让角色随便走动 |
| 需要快速交代角色关系 | 用站位（桌后坐 vs 桌前站=上下级；桌后坐 vs 桌上坐=朋友） | 站位=最经济的 backstory 工具 | 用对话解释"他是我的老板" |
| 需要交代场地地理 | 让角色移动**揭示**关键位置（窗/门/道具） | 观众通过角色运动自然消化空间信息 | 静态全景展示空间=暴露信息、打断叙事 |
| 需要解决空间分离 | 角色走入对方画框 / 切双人镜 / 横摇（pan） 从 A 到 B | 观众需要知道角色间的空间关系 | 让角色一直分开拍=观众空间混乱 |
| 需要引导观众注意力 | 让角色**远离**关键信息（走入另一房间）→观众被迫集中听 | "走开"制造注意力聚焦 | 让讲述者贴近听众=观众分心 |
| 需要标点化动作 | 让角色站起来/移动/拿东西=感叹号/问号/句号 | 调度=视觉标点 | 用对话做标点=沉重 |
| 两人关系变化 | 只有两种戏剧运动：**分开→聚拢** 或 **聚拢→分开** | 关系变化=空间变化，让观众"看到"关系 | 关系变了但站位不变=观众接收不到 |
| 关系复杂（分→合→分→合） | 用**手风琴模式**（accordion）调度 | 多次聚散=戏剧弧线的外化 | 只在开始和结尾变=中间过程不可见 |
| 换戏剧块 | 换"舞台"（从灯亮区到暗区/从桌到沙发/从树到礁石） | 保留每块的独特氛围力量 | 整场在一个位置=氛围单调 |

## 5. 摄影机（The Camera）

| 触发信号 | 选什么/做什么 | 为什么 | 反例 |
|---|---|---|---|
| 机位决策 | 回答5个问题：谁的戏？此刻本质是什么？要介绍/保持什么故事点？要引入什么风格/母题？要解决空间分离吗？ | 5问覆盖叙事/情感/信息/风格/空间全部需求 | 凭"好看"放机位 |
| 谁的戏=在谁的头里 | 角色焦虑→机位靠近角色主观视角（POV）（看对方背影） | 观众必须在主角头里才能感受他的情绪 | 机位在"外面"客观拍=焦虑被遮挡 |
| 揭示（Reveal） | 在关键叙事节点用揭示（马头/飞船/角色首次露脸） | 揭示=有冲击力的叙事工具，每个镜都揭示但**戏剧揭示**才有重量 | 平淡信息也"揭示"=稀释力量 |
| 角色入场 | **宣布**角色（announce）——给入场镜头，别让他们"滑进来" | 入场=介绍角色性格/社会地位/戏剧功能 | 主角模糊入场=观众不知道谁重要 |
| 客观 vs 主观摄影机 | 默认客观（第三人称）；需要观众进入角色感知时用主观 | 主观摄影机是强力工具，过度使用削弱力量 | 全程主观=观众疲劳 |
| 主观摄影机 | 只给一个角色（通常主角）；主观视角（POV）≠主观主观视角（POV）是第三人称看到"她看他" | 主观=让观众体验角色正在经历的 | 把 主观视角（POV） 当主观混用 |
| 机位高度 | 默认平视（eye-level）；偏离必须有叙事理由 | 极高/极低角必须由"此刻本质"和全片风格证明 | 为了"有趣"随便用高低角 |
| 压迫感升级 | 随剧情逐场换更长焦 + 机位从高到低 + 最后露天花板（Lumet《12 Angry Men》） | 长焦压缩空间+低角制造压迫=观众潜意识接收 | 全片固定焦距/固定高度=情绪不升级 |
| 镜头选择 | 广角=深焦+物体靠近变快；长焦=压缩空间+物体靠近变慢 | 镜头调制叙述者的"声音" | 不考虑焦距叙事效果=浪费工具 |
| 覆盖（coverage）（覆盖） | "宽/中/近"三件套=平庸的处方；独特设计才能出独特场景 | 覆盖（coverage） 暗示有安全网=阻止真正的视觉探索 | 默认三机位覆盖每场戏=千篇一律 |

## 6. 与演员合作（Working with Actors）

| 触发信号 | 选什么/做什么 | 为什么 | 反例 |
|---|---|---|---|
| 选角 | 演员必须**体现角色核心**（core）；体貌其次 | 核心对=选角对，体貌可改 | 追求外表像而核心不对 |
| 试镜选场 | 选能探索**角色行为与心理关键区域**的场 | 在试镜阶段就验证演员能否到达关键戏 | 选"好演"的场=看不出能否演关键戏 |
| 试镜 | 给 sides（选段）让演员提前准备；试镜不是表演——是过程起点 | Cold reading 对演员不公平、对导演无益 | 临时给 sides=演员只来得及表面化 |
| 看试镜时 | 看：能看到角色吗？演员逐刻在演吗？演员在听吗？演员有预期吗？ | 四项是演员基本功的快速检测 | 只看"演得好不好"=选出快速到位但无深度的演员 |
| 首次通读 | 不纠正表演；只确保听清+回答问题+确认 backstory 清楚 | 通读=破冰+介绍角色给彼此+验证剧本是否成立 | 通读时就要求"表演"=压力过大 |
| 排练 | 把侦探分析**锁进抽屉**——只跟演员谈处境和欲望（具体、不抽象） | 分析对导演有用但对演员太抽象 | 给演员讲"动态关系=我的幸福"=不具体、无操作 |
| 给演员方向 | 用**动作动词**（to accuse/to intimidate/to confront）；禁用形容词（更开心/更悲伤/更愤怒） | 演员能"做"动作，不能"是"情绪 | "能不能更愤怒一点"=演员无所适从 |
| 给演员方向 | 用**事实**而非态度（"他睡了你好朋友" vs "他不可信"） | 事实可演、可操作；态度是判断 | 给态度让演员猜你要什么 |
| 对演员说话 | 对**角色**说话，不对演员；用角色的日常口语 | 让演员留在角色里 | 用抽象术语对演员说=出戏 |
| 演员卡住了 | 问苏格拉底式问题；分享自己的相关经历（真实经历，不编造）；说"我不知道" | 引导演员自己找到答案比给答案更有效 | 假装有答案=被识破=失去信任 |
| 看演员表演 | 问"我相信吗？"——Stanislavsky："不想看到像饿的人，想看到饿的人" | 导演是演员唯一的镜子 | 只看技术对不对=看不到"真不真" |
| 排练够了吗 | "完美排练=浪费的 take"；演员会为镜头留力，导演也该留一手 | 给首 take 保留惊喜 | 排练到完美=实拍时没有新鲜感 |
| 片场指导 | 事先做好调度+机位=把注意力留给演员；片场让演员感觉是中心 | 演员感觉被忽视=表演退缩 | 片场只顾机位=演员变孤儿 |

**核心可执行句**：先问"谁的戏"→拆戏剧块→每块换空间→在叙事节拍切镜/移人→支点=转折时刻→调度让心理变可见→机位5问→给演员动作动词而非形容词→导演是演员唯一的镜子。
