# 导演方法论决策表（剧本→镜头清单）

> 来源：马梅《On Directing Film》（论导演工作：shot list 即电影）+ 普罗费雷斯《Film Directing Fundamentals》（Ch2 动作动机/Ch8 导演可视化）+ 吕美特《Making Movies》（Ch1 主题决定风格/Ch2 导演如何定风格）
> 用途：video-pipeline 阶段一A（整体视觉方案）+ 阶段一B（逐段视觉设计）加载
> 对齐字段：视觉主线 / 场景系统 / 重复母题 / 色彩节奏 / 情绪基调 / 视觉重点 / info_point

## 整体视觉方案决策表（阶段一A）

| 触发信号 | 选什么 | 为什么 | 反例 |
|---|---|---|---|
| 通读全文定方向 | 先答"这条片子是关于什么的"（主题=what），风格=how 从主题推出 | 主题决定每个后续选择（吕美特：cast/look/edit/音乐全由它定） | 先选风格再套内容=De Palma 式"悲剧皮喜剧骨"失配 |
| 主题含混/拿捏不定 | 排除法定方向：不是A不是B，剩下的就是它 | 吕美特《Prince of the City》即此法，主题反过来淘汰风格选项 | 硬编"高大上"方向词，六要素无从落地 |
| 视觉主线定调 | 一句可执行的风格判断（"好风格是看不见的风格"，被感觉到而非被看到） | 风格统一但各片不同（黑泽明三片三风格仍是黑泽明） | 主线写成抽象词（"高级感"）无法约束逐段设计 |
| 场景系统/重复母题 | 从主题派生重复出现的视觉元素，全片呼应 | 观众靠重复读出含义，母题是主题的视觉化 | 母题与主题无关=装饰堆砌 |
| 色彩节奏 | 由主题决定色彩策略（如"秘密世界"→冷灰压抑） | 色彩是主题的直接表现层 | 按平台流行色选=风格漂移源头 |

## 逐段设计决策表（阶段一B）

| 触发信号 | 选什么 | 为什么 | 反例 |
|---|---|---|---|
| 一段一个新信息/新想法 | 换镜头：每个想法配一个新画面 | 马梅：电影由切镜讲故事，叙事性旁白=替观众宣布"注意重点来了" | 一个镜头塞多个想法=观众漏接 |
| 段内只有单一动作 | uninflected 无修饰镜头（茶杯/勺子/门），含义交给剪辑 | 干净的并列图像让观众自己产生火花（爱森斯坦） | 镜头内做戏（演员表情+运镜+音效三重暗示）=narration 不是 drama |
| "他在找看门人"这类内心意图 | 拍不出"找"这个意图→切到下一个镜头表达它 | 马梅：你只能拍"一个人转身"，"找看门人"要用下一镜（看门人）讲 | 让演员"演努力找"=表演代替剪辑 |
| 段内人物要走动/坐下/转身 | 只有故事动作或外化内心时才让人物动 | 普罗费雷斯：无动机的动作是戏剧张力之敌 | 为了"画面活"让人站起来=arbitrary behavior |
| 镜头动机存疑 | 每个镜头问"为什么需要这个镜头" | 普罗费雷斯：一切运动（人物/摄影机）须有动机 | 运镜炫技无动机=装饰 |
| 心理状态要传达 | 转译成可见行为再设计镜头（psychology → behavior） | 观众只能看见行为，镜头设计对象是行为不是心理 | 直接 prompt "他内心焦虑"=H3 无法执行 |
| 镜头清单编制 | 拍前编 shot list（马梅：电影在 shot list 里就导完了，现场只是执行） | 计划即电影；素材不够时"我还缺一个镜头"要在拍前发现 | 现场即兴+后期补救=素材缺口 |

## 核心规则

1. **一镜一想法**（马梅）——镜头数=想法数，切镜即叙事；镜头内堆想法必然漏接
2. **一切动作须有动机**（普罗费雷斯）——人物动/镜头动/切镜都要能回答"为什么"
3. **主题决定一切**（吕美特）——what 决定 how；视觉主线/母题/色彩全部从主题推出，不反着来
4. **心理学→行为**（普罗费雷斯）——所有抽象情绪先翻译成可见行为，才进入镜头设计
5. **计划先于现场**（马梅）——shot list 是导演工作的本体，shot list 定稿=电影定稿

## 对 video-pipeline 阶段一的适配

- 阶段一A：方向卡生成前先强制回答"这条片子 about 什么"（一句话主题→一句话视觉主线），六要素从主线派生，禁倒推
- 阶段一B：每段设计自检"本段想法数=镜头需求数"；情绪基调必须写成可见行为（H3 可执行），禁纯心理词
- 口播管线单机位口播无人物调度，普罗费雷斯"人物动作动机"弱化为"视觉元素更替动机"（每个画面元素出现要有理由）
- `director_llm.py` 逐段设计 prompt 已含情绪基调字段，本表提供其合法性判据（可见行为 vs 心理词）
