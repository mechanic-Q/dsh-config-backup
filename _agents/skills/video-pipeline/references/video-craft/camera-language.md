> 用途：video-pipeline 阶段4（分镜增强 shot_type）+ 阶段3（导演设计）
> 对齐字段：shot_type / 节奏意图 / info_point

## 景别选择决策表

| 触发信号（台词/情绪/信息点） | 选什么景别 | 为什么 | 反例 |
|---|---|---|---|
| 开场/交代环境/建立空间 | ELS（远景全景） | 观众需要知道"在哪"；人物小=环境为主 | 一上来就特写=观众迷路 |
| 全身动作/走动/大肢体 | LS（长镜头：头到脚） | 需要看完整肢体动作 | LS拍特写对象=细节丢失 |
| 中等动作/姿态/身体语言 | MLS（中长景：膝盖以上） | 看到肢体+部分背景 | 全程MLS=幻灯片感 |
| 小动作/表情+背景 | MS（中景：腰部以上） | 看清表情+保留环境联系 | MS拍大动作=出画 |
| 表情/情绪/个人空间 | MCU（中近景：胸肩以上） | 进入角色个人空间 | MCU拍群体=太挤 |
| 强调情绪/关键信息 | CU（特写：面部） | 强制观众聚焦 | 全程CU=视觉疲劳 |
| 极端强调/细节/抽象 | ECU（大特写：局部） | 创造抽象/冲击力 | ECU拍人脸=情绪反而丢失（太多在画外） |

### 景别选择规则

1. **功能驱动**：先问"观众需要看到什么"→ 景别服务于这个回答
2. **交替原则**：避免连续同景别（MS→MS→MS=幻灯片）；相邻景别差异要够大（避免 jump cut）
3. **特写是子弹**：不用于装饰，用于"必须强调"的信息点
4. **ECU 陷阱**：极端近景会创造抽象而非情绪——越近不一定越有情绪

## 机位高度决策表

| 触发信号 | 机位高度 | 效果 |
|---|---|---|
| 对等/共情/正面交流 | 平视（eye-level） | 观众与角色直接对视 |
| 角色弱势/被俯视 | 高角度（high-angle） | 角色被压低/渺小 |
| 角色强势/权威感 | 低角度（low-angle） | 角色被放大/强大 |
| 不稳定/失衡/疯狂 | 荷兰角（Dutch tilt） | 画面倾斜制造不安 |

## 构图规则

1. **三分法**：画面横竖三分线交点=sweet spots，主体放交点上
2. **纵深层**：前景/中景/背景三层都要有内容（receding planes）；前景遮挡物创造深度
3. **headroom/lead room**：人物面朝方向留空间（lead room）；头到画框顶留 headroom
4. **平衡 vs 不平衡**：平衡=和谐稳定；故意不平衡=不安/紧张（按情绪选）
