# 对话调度与移动取景/开放封闭取景决策表

> 来源：卡茨《Film Directing Shot by Shot》Ch9 Staging Dialogue Sequences + Ch12 Mobile Staging + Ch15 Open and Closed Framings
> 用途：video-pipeline 阶段二（摄影师分镜增强）加载
> 对齐字段：shot_type / 节奏意图 / info_point / reference_anchors(subject_position) / per_second_directives(camera)
> ⚠ 对话调度表仅多人对话需求出现时启用（口播管线无真人对话，默认跳过）

## 对话调度决策表（多人对话需求出现时启用）

| 触发信号（可从输入判断） | 选什么 | 为什么 | 反例 |
|---|---|---|---|
| 两主体对话需连续覆盖 | 双人镜头（two-shot）中景/全景 | 身体语言可表关系，整场不用特写也能成立 | 全程切特写=丢失空间关系 |
| 需单主体孤立反应/观点切换 | 正反打（shot/reverse shot）OTS 特写 | 看到孤立反应+视点变化，视线匹配保空间统一 | 无视线匹配=空间碎裂 |
| 需亲密/对视感 | 视线贴近镜头（sight line 靠 camera） | 视线越近镜头越亲密 | 视线直穿镜头=对抗式惊悚 |
| 对抗/紧张关系 | 低角度 hip 镜头（over-the-hip） | 俯仰+低机位=对抗关系 | 温和对话误用=过度戏剧化 |
| 对话走向分离/僵局 | 无眼神交流的纵深调度（in-depth staging） | 缺眼神交流=张力；观众看到一方看不到的反应 | 需中立关系时误用=偏袒一方 |
| 双方对立/疏远 | 背对背/角形调度（90° 分离） | 身体语言传达疏离 | 亲密对话误用=突兀 |
| 高矮差异/权力差 | 不同高度调度（高低角度双人镜） | 高度差=权力差 | 平权对话硬排高度=做作 |
| 主角掌握信息/主导 | 前景主体正面+后景反应同框 | 看得见眼睛的一方主导镜头 | 前景挡主体=信息丢失 |

## 移动取景决策表（Ch12 Mobile Staging）

| 触发信号 | 选什么 | 为什么 | 反例 |
|---|---|---|---|
| 用运动代替剪辑/连接多个机位 | 主体+机位同时移动（sequence shot） | 单镜连接多构图，比剪辑更流动 | 移动无动机=观众晕 |
| 需前景反应+背景动作同框 | 背景主体绕前景走+机位推前景 | 反应与动作同时呈现 | 全拍动作漏反应=信息缺失 |
| 保持构图平衡/主体小幅偏移 | 摇拍 reframe（低调不可见） | 跟随表演维持构图 | 明显 reframe=手忙脚乱 |
| 场景内多兴趣点需链接 | 主体移动引导机位转移中心 | 单镜完成多中心传递 | 多个中心乱切=失去统一 |
| 重要信息需弱化/留白 | 信息放背景/软处理（indirection） | 直给=过度强调；小动作最有力 | 每点都推近=无重点 |

## 开放/封闭取景决策表（Ch15）

| 触发信号 | 选什么 | 为什么 | 反例 |
|---|---|---|---|
| 需观众参与/亲密/心理认同 | 开放构图（open framing，前景遮挡+元素出框） | 纪实感、共享角色视角 | 客观叙事误用=过度主观 |
| 需客观/距离/冷静观察 | 封闭构图（closed framing，主体精心摆位） | 观赏距离、抽离感 | 亲密段误用=疏离 |
| 需强调主体/加入新语境 | 前景框架元素（门框/窗户/前景物） | 框内框=强调+距离（窥视感） | 框架挡信息=剥夺 |
| 需开场的景别落差 | 开场放宽+后接特写（保证 shot size 落差） | 落差制造节奏与推进感 | 开场即特写=没有起伏 |
| 长焦压平前景 | 长焦压缩前景元素遮挡主体 | 隐藏信息、只露部分主体 | 需明确指向时误用=含糊 |

## 核心规则

1. **模式（pattern A/I/L）决定机位，位置（position）决定构图**——先排空间再摆机位
2. **看得见眼睛的演员主导镜头**——视线即权力
3. **移动取景的唯一标准：动机（motivated）**——不编造多余动作，来自故事/表演本身
4. **开放=纪实、封闭=布置，技术意义由上下文决定**——没有绝对优劣
5. **动作圈内外 = 开放/封闭的根源**——圈内=开放亲密，圈外=封闭客观

## 对 video-pipeline 的适配

- 口播管线：对话调度表**不启用**（无真人对话），标注"多人对话需求出现时启用"
- `reference_anchors.subject_position`：科普口播主体=中心正面（封闭构图），类比插画/产品=前景+背景元素（开放构图）
- `per_second_directives.camera`：节奏意图=冲击/关键点时收紧取景（开放→封闭切换）
- POV 段（idx%5==0）：开放构图+前景元素，让观众进入画面
- 拉远/放宽 = 揭示环境；收紧 = 强调信息点

## 升级路径（ponytail）

当前为纯决策表。若未来接入多人对话视频（角色扮演短剧），启用对话调度表，并需按 A/I/L 模式扩展 3-4 人调度决策。
