# 各平台标题定制手册

同一支视频在不同平台的标题是**翻译**，不是复制。本手册给出每个平台的标题机制、可直接套用的公式，并以 2026-09-04 期《每日新中国》（主题：具身智能产业发展打开灵活就业新通道，时长 3:19）为例做示范。

## 0. 通用流程（pipeline 可执行）

1. 从视频提炼三要素：**一句话事件**（具身智能产业政策落地）、**一个数据/反差点**（机器人和就业的关系）、**一类受益人群**（找工作的普通人）
2. 按各平台公式套模板生成标题
3. 抖音/视频号的封面大字与标题**互补不重复**（封面字 6-10 字以内）
4. 标签 3-5 个，必须用平台已有话题词（发布时靠联想下拉命中）
5. 同一素材可出两版标题分两天发布，用 `sau douyin health` / `sau bilibili health` 追踪播放中位数决定保留哪版

## 1. B站（当前表现最好：播放 48-146）

**机制**：搜索+推荐并重；标题上限 80 字，可承载完整信息；知识区受众吃"信息密度"，关键词完整利于搜索。

**公式**：`[系列名 日期]：[事件] + [量化亮点或为什么重要]`；技术类内容用疑问句更好。

**今日实例**：

- 现标题（合格）：《每日新中国 2026-09-04：具身智能产业发展打开灵活就业新通道》
- 优化版：《每日新中国 09-04：具身智能新政落地，这 3 类新职业要爆了》——把抽象的"新通道"换成可数的"3 类新职业"

**标签**：`每日新中国,具身智能,人工智能,中国制造,今日要闻`（保留系列名便于搜索聚合）。

## 2. 抖音（当前痛点：播放个位数、封面点击率 0%）

**机制**：信息流 0.5 秒滑过，标题是钩子不是摘要；上限 55 字但**前 13 字决定生死**；政策通报腔是点击率杀手。

**公式**（任选其一）：

- 反差悬念：`A 开始抢 X 了？这次却先给了你 Y`
- 数字冲击：`3 分钟看懂：XX 为什么突然火了`
- 身份代入：`你的下一份工作，可能和机器人搭伙`
- 口语提问：`XX 是啥？国家为什么押注它？`

**今日实例**：

- 反面教材（实际发布的）：《具身智能产业发展打开灵活就业新通道》——标准政策标题，无点击动机
- 正例：
  1. `机器人要抢饭碗？这次政策先造新饭碗`（反差）
  2. `国家为什么力挺"具身智能"？和你的工作有关`（身份代入）
  3. `都说是下一个风口，具身智能到底是啥`（悬念）
- 封面大字：`机器人 ≠ 抢饭碗`（与标题互补）

**标签**：`科技,人工智能,机器人,涨知识`（≤5 个；避免 #军事 #时政类标签，无资质账号打这类标签会加重限流）。

## 3. 快手

**机制**：老铁文化，信任+实用优先；标题要"讲给普通人听的大白话"，抽象政策词是硬伤。

**公式**：`普通人视角 + 实际利益`；`这波 XX，跟你的钱包有关系`。

**今日实例**：`国家力挺的"具身智能"到底是啥？普通人能靠它干点啥`

**标签**：`科技,机器人,涨知识,正能量`。

## 4. 今日头条

**机制**：推荐+搜索双引擎；30 字硬上限（本仓库 CLI 强校验）；读者偏成熟、关注民生关联；机器审核排斥夸张词但容忍数字与疑问。

**公式**：`事件 + 影响面 + 悬念补充`；数字开头效果好。

**今日实例**：`具身智能产业提速：灵活就业新通道打开，这些岗位需求大涨`

**标签**：`具身智能,人工智能,就业,科技`。发布页话题联想命中平台词库才算数。

## 5. 视频号

**机制**：社交推荐（转发+点赞驱动），成熟用户占比高；标题要让**转发的人有面子**——家国叙事、正面情绪、生活关联表现最好。

**公式**：`正面事实 + 共鸣点 + 转发理由`。

**今日实例**：`中国机器人产业再提速，一批新职业正在生长`

**标签**：`中国科技,正能量,人工智能`。封面大字：`新产业 新机会`。

## 6. 小红书（⛔ 已停用，仅作将来恢复时参考）

> 2026-09-05 决定：现有 patchright 自动化方式在小红书封号风险过高，通道已关闭（`conf.py` 的 `XIAOHONGSHU_ENABLED = False`）。以下内容留待有更安全发布方式后使用。

**机制**：搜索种草逻辑，标题吃 emoji 和关键词；"干货感"优于"新闻感"。

**公式**：`emoji + 话题词 + 干货承诺`。

**今日实例**：`🤖一文看懂具身智能：风口上的新职业机会`

**标签**：`人工智能,职场,科普,涨知识`。

## 8. 与发布链路的衔接

- 各平台标题通过 `sau <platform> upload-video --title ... --tags ...` 传入
- 固定标签组在 `conf.py` 的 `PLATFORM_EXTRA_TAG_POOLS` 维护，发布时 `--extra-tag-pool` 按内容类型选组
- 参加活动用 `--activity`（活动名来自 `list-activities`），只参加与内容契合的活动
- 发布后 24-48h 用 `sau douyin health` / `sau bilibili health` 查看作品数据，周度对比播放中位数趋势
