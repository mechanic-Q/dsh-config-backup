## 踩坑

- **假 Ledger 缺 flush，短路测试直接 AttributeError**：`_check_frames` 收尾现在必 flush，测试双必须与真实试件同接口，否则整文件红。修法：`FakeLedger.flush()` 空实现（该测试只关心台账内容、不关心落盘）。
- **s08 flush 断言第一版假红**：按顶层键 `"s08.segments"` 查 JSON 是错的——`Ledger.record("s08.segments", …)` 走点路径嵌套成 `{"s08": {"segments": …}}`，必须按嵌套结构取。
- `Ledger.flush` 自身是幂等合并 + 原子写 + 自吞异常（0908 根治双计），所以这两处 flush 不会因写盘失败阻断 s08 主链；无需再包 try/except。
