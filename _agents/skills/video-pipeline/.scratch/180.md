## Decisions so far

- **证据桶接生产**（[#182](https://github.com/mechanic-Q/video-pipeline/issues/182) → PR #183 / 9556dbc）：生产证据桶按判官四象限归档进 `<slug>/_frames/evidence/{1-confirmed,2-judge-found}/` 并写同构 `manifest.json`，`load_evidence_buckets` 双路合并（生产 + 离线）读取——素材不再只靠一次性 t15 离线回放，每期生产自动进训练链；证据行落 `sha256`（`verify-evidence` 对账，账实不符退出码 1），人工真值三件套补齐 `ground_truth_verdict`（词表 正常/翻转/翻转90/翻转180/倾斜）。顺带修掉 `append_records` 整行 upsert 重跑会冲掉人工真值的洞。

- **人审指认即落账**（[#190](https://github.com/mechanic-Q/video-pipeline/issues/190) → PR #196 / 862bbbc）：指认一次即落三处账——`manifest.json` 记 `4-human-flag`/`human_flag` 条目（帧冻结、sha256 对盘上那张）、数据集该行行内 `evidence_frames` 追加同一路径四字段条目、台账 `human_flags` 平键并在回调返回前 `flush`；去重键沿用 `(category,sid,round)`，重复指认复用原条目不重拷帧；证据桶词表扩四元组（第四类人审正类，与判官四象限不同源），读取侧经 `evidence_frame_path` 兼容存量纯路径行。

- **读取侧真值帧**（[#191](https://github.com/mechanic-Q/video-pipeline/issues/191) → PR #197 / 705d6a4）：训练链取帧收成一个解析点 truth_frame（行内证据帧 → 证据桶帧 → 工作帧），账与盘 sha256 不符即弃帧告警、绝不回落到重烧后的工作帧；frame_stale 行两侧都不进池——把工作帧覆盖重写后仍取冻结帧，是这条的唯一硬验收。

- **归档门语义收紧**（[#192](https://github.com/mechanic-Q/video-pipeline/issues/192) → PR #198 / 8e34ff5）：`_archive_evidence_buckets` 自身也把门——判官缺席（非 dict / `ok=False`）直接返回、不建桶目录、不写清单（旧实现只在调用点挡过一次，直接调用时会无条件落一份空 manifest，等于对「本轮无类别证据」作伪证）；类别改白名单闭集，只写 1-confirmed / 2-judge-found，4-human-flag 只归人审指认回调；docstring 逐类交代写者与时机，`3-unfixed` 如实标注「生产侧暂无写者、归 #194 的 s08 收尾」；fail-open 测试从「空列表 + 只断言返回值」改成「非空证据 + 查 manifest 未落盘」，并补白名单对抗用例（两个变异均打红验证）。

- **存量证据回填与失效标注**（[#193](https://github.com/mechanic-Q/video-pipeline/issues/193) → PR #199 / f25b7e5 + 数据 ecb1572）：10-19 六条按 sha256（不按文件名/时间戳）去重各回填一条代表帧——`human_flag/shotNN_20261020_230641.jpg`（230641 与 010052 字节相同，即 2026-10-22 复判判出翻转的那份帧）与 shot19 的 `human_flag/shot19.jpg`，其余副本是 VLM 判过「正常」的指认前快照或与工作帧同 sha 的复检前快照，写进行内等于往正类池掺误标；10-02 shot08 无冻结副本（复检重抽覆盖了工作帧、该期 evidence 目录从未生成）如实标 `frame_stale`+原因，人工结论一字未动。机制：写入幂等改 sha 级预去重（原先按帧路径比，同 sha 不同文件名会叠第二条）；stale 行不从两侧进池但仍留在判定数里（`gt.load_labeled` 只按 `user_flagged` 算）。至此「账上有指认、行内无证据」的存量窟窿补齐，证据链历史侧闭环。

- **3-unfixed 收尾补写**（[#194](https://github.com/mechanic-Q/video-pipeline/issues/194) → PR #200 / 3e754e2）：s08 收尾 `still_flipped` 非空时，由 `_archive_unfixed_evidence`把每段「最后一次复检轮」的在盘定罪帧拷进 `_frames/evidence/3-unfixed/`，并按同一 manifest写口追加同构条目——「修不好」的最难正类，判据是收尾仍翻本身、不要求判官在场；梯队声明轮没落地（重烧被跳过）时退回该段真正最后一次复检轮，缺帧宁缺不伪造，重跑按 `(category,sid,round)` 幂等。至此四类证据桶生产侧各有写者，ADR 0008 决策 6 兑现。
