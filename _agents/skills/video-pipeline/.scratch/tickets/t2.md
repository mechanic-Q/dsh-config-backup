## What to build

训练链取帧时，人工点名的行拿到的是**当时定罪的那一帧**，而不是按文件名排序碰巧第一、可能已被重烧覆盖的工作帧。账实不符就弃帧告警，绝不静默回落。没有可用帧的行干脆不进池。

## Acceptance criteria

- [ ] 存在单一解析点承担「行内证据帧 → 证据桶帧 → 工作帧」优先级；`user_flagged=True` 时先取证据帧
- [ ] sha256 与账上不一致 → 弃该帧并告警，**不回落工作帧**；整行无可用帧 → 返回空
- [ ] `rotate4_pool` 对该行取到冻结帧路径；把工作帧覆盖重写后再取，仍是冻结帧（本次唯一硬验收）
- [ ] `frame_stale` 行不出现在 `pool` / `pos` 任何一边
- [ ] `frames_of` 保持纯物理列举语义，其余物理列举消费方（导出/统计/校准）行为不变
- [ ] 纯字符串形态的存量 `evidence_frames` 仍可消费（无 sha256 时现算比对）
- [ ] 对应测试小节全绿
