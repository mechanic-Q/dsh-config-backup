## What to build

当有人在确认门④或 CLI 指认某段翻转，这次判断要在**当下**变成可追溯的账：证据桶词表新增 `4-human-flag`，定罪帧冻结并记 sha256，`manifest.json` 追加条目，数据集该行行内 `evidence_frames` 追加同一张帧，台账在回调返回前已经落盘。判官在不在场都不影响这条链。

## Acceptance criteria

- [ ] 指认一段后 `_frames/evidence/manifest.json` 出现 `category=4-human-flag`、`round=human_flag` 的条目，且 `frame` 与 `sha256` 与盘上冻结帧一致
- [ ] 同一行行内 `evidence_frames` 出现**同路径**条目，`{frame, sha256, round, category}` 四字段齐
- [ ] 同一 `(category, sid, round)` 重复指认不产生重复条目（沿用既有去重键）
- [ ] 指认回调返回时台账已 flush：`human_flags` 顶层平键可读到本次记录
- [ ] `EVIDENCE_CATEGORIES` 为四元组，`CATEGORY_NOTES` 补齐人审口径说明
- [ ] 新写口只补 `evidence_frames` 字段，**不改**该行其它字段（`vision_verdict` / `user_flagged` / `judge_*` 原值不变），且仍过 `write_rows` 单一写口
- [ ] 既有类别等号断言（证据训练链测试里 `set(by_cat) == set(EVIDENCE_CATEGORIES)` 一类）同步改为四类口径并全绿
- [ ] 全量测试跑器绿
