# 检索-本地爬虫按需启用

> **触发**：常规搜索/抓取腿全部空（AnySearch 422、Jina 401、直连只回导航）／目标是 JS 重渲染页面（SPA、瀑布流、需要滚动的列表）／要整站爬或批量抓同构页
> **验证**：`bash ~/.dsh/bin/crawler.sh status` 显示 Docker running 且 crawl4ai 是 healthy；`curl -s -o /dev/null -w '%{http_code}' 'http://127.0.0.1:28888/search?q=test&format=json'` = 200

## 首选

**默认全关**（容器 + Docker Desktop 都可关）。先问用户，别自作主张拉起。

一条命令搞定开关，**从打开 Docker Desktop 开始算**：

```bash
bash ~/.dsh/bin/crawler.sh up      # 冷启动实测 18s：7s 引擎就绪 + 容器 healthy + searxng 200
bash ~/.dsh/bin/crawler.sh status  # 看当前状态
bash ~/.dsh/bin/crawler.sh down    # 停容器 → 退 Docker Desktop → 实测 18s 后引擎真关
```

脚本内部顺序：`docker desktop start` 失败才回落 `"Docker Desktop.exe"` → 轮询 `docker info` 最长 180s → `docker start` → 等 crawl4ai healthy → 探 searxng 端口；down 走 `docker desktop stop`，没关干净再 `taskkill /T /F`，最后确认引擎不可达。

**SearXNG 当搜索腿**（bing 0 命中时补位，别加进常驻 enabledEngines）：
```bash
curl -s 'http://127.0.0.1:28888/search?q=<urlencoded>&format=json&language=zh-CN' | head -c 3000
```
返回 `results[]{title,url,content}`；上游 brave/ddg/google 常被墙或 CAPTCHA，只当兜底。

**crawl4ai 当抓取腿**（JS 渲染 / 反爬站点）：
```bash
TOKEN=$(grep -o 'CRAWL4AI_API_KEY: .*' ~/.dsh/.credentials.yaml | sed 's/CRAWL4AI_API_KEY: //')
curl -s -m 120 -X POST http://127.0.0.1:11235/crawl \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"urls":["<URL>"],"browser_config":{"type":"BrowserConfig","params":{"headless":true,"magic":true}},"crawler_config":{"type":"CrawlerRunConfig","params":{"cache_mode":"bypass"}}}'
```
返回 `results[0].html` / `.markdown`。实测知乎 1.6s / 265KB HTML。

## 别再来

| 弯路 | 为什么不通 |
| --- | --- |
| 只 `docker start` 不先确认 Desktop | 引擎没起时 `docker start` 直接报 `cannot find the file specified ... dockerDesktopLinuxEngine` |
| 把 searxng 加进 deep-search 的 enabledEngines 常驻 | 容器关着时每轮白等超时 |
| 把 web.fetchProvider 换成 free-search 接管 | 丢 AnySearch extract（pypi/arxiv 强项），且 crawl4ai 仍不在链里 |
| 不带 Bearer 调 11235 | `{"detail":"Authentication required"}` 401 |
| 不带 `magic:true` 抓知乎 | 403 |
| 对同一个 403/422 换 UA 重试 | 同通道同结果，换腿才有用 |

## 注意

- token：`docker inspect crawl4ai --format '{{range .Config.Env}}{{println .}}{{end}}' | grep CRAWL4AI_API_TOKEN`；已写进凭据 `refs: CRAWL4AI_API_KEY`（2026-10-21）。**容器关着时这条命令也会失败**，需要先 up。
- 端口：crawl4ai `127.0.0.1:11235`、SearXNG `127.0.0.1:28888`（**不是 8888**）。
- 横评基线：6 URL 上 crawl4ai 5/6、AnySearch 4/6，失败集合不重叠（crawl4ai 盲区 linux.do、AnySearch 盲区知乎 422）。
- 计时实测（2026-10-21，WSL2 后端）：up 18s（冷，含 Desktop 启动）、down 18s（含 Desktop 退出）。所以它适合"一次会话集中抓几个难点页面"，不适合每条 URL 都开关。
