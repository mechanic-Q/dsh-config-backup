# 检索-搜索只回 8 条

> **触发**：web_search 只回 8 条 / 改了 searchMaxResults 不生效 / 想调大结果数
> **验证**：改完重启，让 agent 跑一次 web_search 数 sources.length；仍是 8 说明没改到 preset

## 首选

先认清两件事再动手：

1. **profile patch 里的 `- id: tool-web` 是无效的**。`dsh-web-app` bundle 里有 `- id: tool-web / disabled: true`，真正生效的是 **preset 内部**那一行。
2. **AnySearch 服务端单次上限就是 10 条**（实测 requested=15/20 都回 10）。调到 15 也只有 10。

确认当前生效值：
```bash
# 看 preset 内的 tool-web（不是顶层那个）
grep -n -A6 'id: preset-ptc' <dump> | grep -A5 'id: tool-web'
```

真要改，只能整段覆盖 preset（**必须完整抄全部 plugins，漏一个就少一个工具**）：
```yaml
- id: preset-ptc
  name: '@deepseek-ai/dsh-agent-preset'
  config:
    id: ptc
    order: 2
    plugins:
      # ... 完整列表，其中 tool-web 加 searchMaxResults: 15
```

## 别再来

| 弯路 | 为什么不通 |
| --- | --- |
| 在 profile patch 写 `- id: tool-web / config: searchMaxResults: 15` | 这行被 web-app 置 `disabled: true`，配置不生效 |
| 用 `--patch overlay.yml` 只写 tool-web 想增量覆盖 | patch 会**整段替换** `config.plugins`：实测 33 个 plugin 变成 1 个 |
| 以为调到 15 就有 15 条 | AnySearch 单次上限 10 |

## 注意

- 默认 8 是 `@deepseek-ai/dsh-tool-web` 的 schema 默认值（`searchMaxResults: z.number().default(8)`），不是 bug。
- 想多要结果，正确做法是**换多查询**（`multi_search` / `anysearch_batch_search` 一次 5 条 query），而不是调大单次上限。

证据：`/tmp/final-dump.yml` L393（顶层 disabled）vs L846/L1014/L1279（三个 preset 内）
